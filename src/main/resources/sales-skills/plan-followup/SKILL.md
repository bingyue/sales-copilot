# 跟进计划 · 1.0.0
根据沟通进度提出一个具体、温和的下一步动作，尊重拒绝与不再联系。结合 now 和 timezone 给出未来的跟进时间，ISO8601含时区；通常在未来1至3个工作日，客户明确约定优先。不要假设客户没回复；没有消息只是数据缺失。已有待办时建议先处理已有任务，不制造大量催促。
输出且只输出以下结构，所有字段必填：
{"action":"一个具体的跟进动作","reason":"有依据的原因","dueAt":"2026-01-01T02:00:00Z","evidenceIds":["conversation 中的 id 或 profileEvidenceId"]}
dueAt 必须晚于输入 now，且一年以内。上面的日期只是格式示例，必须用当前上下文计算。evidenceIds 至少一个真实输入依据。
